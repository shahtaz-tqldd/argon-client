# argon admin frontend
This is the admin interface for controlling argon admin

# tech stack
- vite + react + javascript
- tailwind css
- shadcn


# Chatbot creating flow
1. Create with basic details
 - name
 - description
 - logo
 - timezone
 - language
 - plan

2. Step 2: Redirect to configuration page
 - General Info (Human Handoff, Knowledge base)
 - Upload Knowledge
 - Widget settings
 - Connects channel
 - Publish
 - Test your bot
